# Media font provenance

`lv_font_notosanssc_regular_28.c` remains the original Espressif example font.
The application uses a mutable `lv_font_t` copy with the supplemental font below
as its fallback; the generated const objects are not modified.

`lv_font_notosansjk_regular_28.c` is generated by the official
[lv_font_conv](https://github.com/lvgl/lv_font_conv) 1.5.3, 28px, 1bpp, uncompressed.
Source: [Noto Sans CJK KR Regular](https://github.com/notofonts/noto-cjk/blob/f8d157532fbfaeda587e826d4cd5b21a49186f7c/Sans/OTF/Korean/NotoSansCJKkr-Regular.otf).
Source SHA256: `6bcb2a0703aa137e874fc2dffa85f6c21ba9a67fa329e81b8c801663af7e992a`.
Copyright 2014–2021 Adobe; SIL OFL 1.1, included in `OFL-Noto-CJK.txt`.

Coverage: Japanese kana U+3040–30FF and U+31F0–31FF; Hangul Jamo U+1100–11FF,
U+3130–318F, U+A960–A97F, U+D7B0–D7FF; all 11,172 modern Hangul syllables
U+AC00–D7A3. Existing SC glyphs cover common kanji. This is not every Unicode
character, not an emoji font, and not region-specific Japanese kanji typography.

Regenerate with `bash scripts/generate_media_font.sh` from the repo root.
Node/npm and network are needed only for regeneration. Generated C is tracked,
so normal IDF builds and device runtime do not need Node, network or an SD card.
The converter comment records the temporary source path used for that run;
this path is provenance, not a compiler dependency.
