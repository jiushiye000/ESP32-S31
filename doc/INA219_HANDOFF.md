# INA 驱动交接

## 当前状态

- 工程为 Linux + ESP-IDF v6.1，目标芯片 ESP32-S31。
- 组件位于 `components/ina`，公共 API 声明集中在 `components/ina/ina_driver.h`。
- 型号驱动相互独立，位于 `components/ina/src/`：`ina169_driver.c`、`ina219_driver.c`、`ina226_driver.c`。
- 应用通过公共头文件选择对应型号的初始化和读取 API；INA219 与 INA226 不再通过编译宏切换。
- 当前应用入口是 `main/main.c`，使用 INA169 的 ADC 输出测量接口。
- INA169 测量结构为 `ina169_measurement_t`；INA219/INA226 共用 I2C 测量结构 `ina_i2c_measurement_t`。
- I2C 驱动使用 ESP-IDF master API，不依赖 INA226 Component Registry 组件。

## 当前接线与配置

| INA219 模块 | ESP32-S31 / 电路 |
|---|---|
| `SDA` | GPIO42 |
| `SCL` | GPIO38 |
| `VCC` | 3.3 V |
| `GND` | ESP32 GND；与被测电源负极共地 |
| `IN+` | 被测电源正极侧 |
| `IN-` | 负载正极侧 |
| `ALE` | 当前未使用，可不接 |

电流测量时，`IN+` 和 `IN-` 要串在被测电源正极与负载之间。INA219 的母线电压寄存器测量 `IN-` 相对 GND 的电压；不需要 INA226 模块上可能出现的独立 `VBS/VBUS` 接线。不同模块的丝印可能不同，应以具体模块原理图为准。

INA219 的 A0、A1 都接地时，预期 7 位地址为 `0x40`。本次调试扫描也发现 `0x40` 有 ACK。

## 型号驱动参数

INA169 当前由 `main/main.c` 使用，ADC 输入为 GPIO1。换算参数在 `components/ina/src/ina169_driver.c` 中：分流电阻假设为 `100 mΩ`，输出负载电阻为 `10 kΩ`，INA169 跨导参数为 `5 kΩ`。硬件实际阻值若不同，需要同步修改参数。

INA219 和 INA226 的配置分别位于各自驱动文件，不通过宏切换：

- 两者当前都配置为 I2C `100 kHz`，分流电阻假设为 `100 mΩ`，最大电流假设为 `800 mA`。
- INA219 地址为 `0x40`，配置寄存器为 `0x3D57`，Current LSB 为 `25 µA/bit`，母线电压每 bit 为 `4 mV`，Power LSB 为 `500 µW/bit`。
- INA226 地址为 `0x44`，配置寄存器为 `0x4127`，母线电压每 bit 为 `1.25 mV`，分流电压每 bit 为 `2.5 µV`。
- 当前 I2C 驱动引脚配置为 SDA GPIO1、SCL GPIO0；请按实际板级接线确认。

**分流电阻值尚未由模块实物标记确认。**烧录前请检查分流电阻丝印；若不是 `R100` / `0.1 Ω`，应修改所用型号驱动中的分流电阻配置。分流电阻设错会直接影响电流和功率校准。

## 已验证现象

INA219 测试日志示例：

```text
Bus: 3.356 V (raw=0x1A38)
```

计算为 `0x1A38 >> 3 = 839`，`839 × 4 mV = 3.356 V`。另一读数 `raw=0x1A32` 换算为 `3.352 V`。用户确认这与万用表约 `3.37 V` 的读数相符，说明 INA219 的母线电压寄存器及换算分支正在工作。

INA226 驱动会在初始化时访问 `0x44` 并读取 manufacturer ID；INA219 驱动使用 `0x40`，不进行该检查。确认应用调用了匹配芯片型号的 API，并保证 I2C 地址及硬件连线一致。

## 构建、烧录和监视

在工程目录激活环境并构建：

```bash
source ./esp_env.sh
idf.py build
```

烧录并打开串口监视器（端口按实际设备修改；本次设备曾使用 `/dev/ttyUSB0`）：

```bash
idf.py -p /dev/ttyUSB0 flash monitor
```

退出 ESP-IDF Monitor 可按 `Ctrl+]`。Monitor 正运行时，先退出再构建或烧录，避免使用到旧 ELF/bin。

## 注意事项与后续排查

- INA219 的母线电压、电流和功率寄存器是分开读取的，芯片转换可能在读取之间更新；负载变化时，单行日志里的三项数值不一定来自完全相同的转换时刻。
- 若要求显示功率严格等于同一行电压乘电流，可在应用侧用同一轮读到的电压、电流计算功率，而不直接显示硬件 Power Register。
- INA226 与 INA219 的母线电压分辨率、配置寄存器、校准公式和地址不同；应用应调用各自独立的 `ina219_*` 或 `ina226_*` API。
- 当前 INA226 分支地址保留为 `0x44`，是先前扫描该 INA226 模块时发现的地址；INA226 A0/A1 接地通常应为 `0x40`。切回 INA226 前应重新扫描并确认模块地址脚和实际 ACK 地址。
